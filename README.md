# Mantis: Defeat the Creatures (მანტისი: დაამარცხე არსებები)
ლაივის ლინკი (live link) : https://zazamirotadze.itch.io/mantis-defeat-the-creatures

2.5D სამოქმედო-საბრძოლო არენის თამაში (Action Combat Fighting Game), სადაც მთავარი პერსონაჟია **მლოცველი (Praying Mantis)**. მოთამაშე ებრძვის რეალური ბუნების 8 განსხვავებულ არსებას, რომელთაგან თითოეული იბრძვის თავისი დამახასიათებელი ბიოლოგიური თვისებებითა და უნიკალური გარემოს მქონე არენაზე.

---

## 🎮 როგორ გავუშვათ თამაში (How to Run)

თამაში აწყობილია HTML5 Canvas-სა და Web Audio API-ზე და არ საჭიროებს არანაირი გარე ბიბლიოთეკის ან npm-ის ინსტალაციას:
1. უბრალოდ გახსენით `index.html` ნებისმიერ ბრაუზერში (Chrome, Edge, Firefox, Safari) მასზე ორმაგი დაწკაპუნებით.
2. ან გაუშვით ლოკალური სერვერი:
   ```bash
   npx serve .
   # ან
   python -m http.server 8080
   ```

## 🕹️ მართვა (Controls)

| ღილაკი | მოქმედება | აღწერა |
|---|---|---|
| **A / D** ან **◄ / ►** | მოძრაობა | მანტისის გადაადგილება მარცხნივ / მარჯვნივ |
| **W / Space** ან **▲** | ნახტომი (Jump) | მაღალი ნახტომი და ფრთების ფრთხიალი |
| **J / Z** ან **Mouse Left Click** | ნამგალა ჭრა (Slash) | 3-დარტყმიანი კომბო ნამგალა წინა კიდურებით, ბოლოში ორმაგი გადაჯვარედინებული ჭრით |
| **K / X** ან **Mouse Right Click** | ჩასაფრებიდან ნახტომი (Pounce) | წინ ელვისებური გაქანება და დაჭერა |
| **L / Shift / C** | ბლოკი / პარი (Parry) | ნამგალების გადაჯვარედინება. სწორ მომენტში დაბლოკვისას (Parry) მოწინააღმდეგე შეცბუნდება (Stun) 1.2 წამით |
| **ESC** | პარამეტრები | ფერების შეცვლა, ხმის რეგულირება, ტურის არჩევა |

*მობილურზე / პლანშეტზე ხელმისაწვდომია ეკრანზე განთავსებული სენსორული ღილაკები.*

## 🎨 მანტისის ფერების მორგება (Customization)

პარამეტრების (Settings - ⚙️) მენიუდან შეგიძლიათ აირჩიოთ მანტისის 6 უნიკალური შეფერილობა:
1. **კლასიკური მწვანე (Classic Green)** — ნაგულისხმევი მლოცველი
2. **ორქიდეის ვარდისფერი (Orchid Pink)** — ყვავილოვანი ორქიდეის მანტისი
3. **ხმელი ფოთოლი (Dead Leaf Brown)** — შემოდგომის ფოთლის იმიტაცია
4. **ოქროსფერი მზე (Golden Sunburst)** — უდაბნოს ოქროსფერი შეფერილობა
5. **მოჩვენება ნეფრიტი (Ghost Jade)** — მისტიკური ღია მწვანე
6. **კიბერ ნეონი (Cyber Obsidian)** — ფუტურისტული ნეონ-იასამნისფერი
